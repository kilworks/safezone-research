- A workflow run cut by the token quota leaves fixers' edits on disk: read the journal (`journal.jsonl`) before resuming.

New theorem lines in `ko/theory/` use `**정리 T-xxxx.**`.

- A Python script passed through a Bash heredoc loses its backslashes: write it to the scratchpad with Write, then run it.
- Wayback `id_` captures are stored gzip as downloaded; `tools/page_text.py` decompresses on read so hashes stay those of the bytes downloaded.
- archive.org refuses connections above about 15 requests per minute: `tools/wayback.py` paces at 5 s.
- `np.linalg.inv` saturates near 1e16 on near-singular chains: exact answers need `fractions.Fraction`.
