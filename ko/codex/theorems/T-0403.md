# T-0403

[theory/04-probabilistic-items.md](../../theory/04-probabilistic-items.md)에서 발췌했습니다. 전체 맥락, 증명, 테스트는 그곳에 있습니다.

**정리 [T-0403](../theorems/T-0403.md).** $S : \{0, \dots, M\} \to [0, 1]$이 단조 비감소이고 $S(0) = 0$이라 합시다. 지금 마시고 다시는 마시지 않을 때의 가치는 $D(h) = \frac{1}{10}S(h^+) + \frac{9}{10}S(h^-)$입니다. 지금 마시는 것이 끝까지 마시지 않는 것보다 엄밀하게 나은 것은 $D(h) > S(h)$일 때, 그리고 그때에 한하며, 이는 다음과 같이 읽힙니다.

(a) [U-0004](../unknowns.md#u-0004) 해석 A에서 $h \le \ell$(실패하면 죽음)일 때: $S(h^+) > 10\,S(h)$. 특히 실패하면 죽는 HP에서는 $S(h) \ge 1/10$이면 절대 마시지 않습니다.
(b) 해석 A에서 $h > \ell$일 때: $S(h^+) - S(h) > 9\,\bigl(S(h) - S(h - \ell)\bigr)$. 성공 시 얻는 생존 확률이 실패 시 잃는 생존 확률의 아홉 배를 넘어야 합니다.
(c) 해석 C에서는 $h^- = \max(h - \ell, 1)$로 (b)와 같습니다.
(d) 어떤 해석이든 필요조건은 $S(h) < \frac{1}{10} + \frac{9}{10}S(h^-)$입니다.

*증명.* (a) $S(h^-) = S(0) = 0$이므로 $D(h) > S(h)$인 것은 $S(h^+)/10 > S(h)$일 때입니다. $S(h) \ge 1/10$이면 $10S(h) \ge 1 \ge S(h^+)$입니다. (b), (c) $D(h)$에서 $S(h) = \frac{1}{10}S(h) + \frac{9}{10}S(h)$를 빼고 10을 곱합니다. (d) $S(h^+) \le 1$. $\square$

이것은 "최후의 수단으로만 마셔라"라는 규칙의 정확한 형태입니다. $S$의 단조성 외에는 환경에 대한 어떤 가정도 필요하지 않습니다. 단조성은 매 단계가 HP에 의존하지 않는 확률로 뽑은 이동량 $\delta$를 적용하고 $[0, M]$으로 자르며 0이 흡수 상태일 때 성립합니다. 결합(coupling)으로 증명합니다. $x \le y$인 두 참가자를 같은 추첨으로 돌립니다. $x = 0$이면 0에 머물고, 아니면 자르기가 비감소이므로 $\mathrm{clip}(x + \delta) \le \mathrm{clip}(y + \delta)$이고, 따라서 순서 $x \le y$는 모든 단계에서 유지되며 $x$가 살아 있으면 $y$도 살아 있습니다. 그러므로 $S_T(x) \le S_T(y)$입니다. 움직임이 HP에 의존하는 환경에 대해서는 단조성을 주장하지 않습니다.

*라벨:* `DERIVED`(모델에 대한 진술). 게임에 적용하는 것은 [U-0004](../unknowns.md#u-0004)(어느 쪽이 (a)인지 (c)인지)에 대해 `CONDITIONAL`이며, 환경과 [U-0009](../unknowns.md#u-0009)에 의존하는 $S$가 필요합니다. *테스트:* `test_t0403_one_drink_decision_boundary`(모든 $h$, [U-0004](../unknowns.md#u-0004)의 두 해석 모두, $M = 100$의 144개 연쇄에서 정확히 계산한 $S_T$에 대해: 손실 1부터 20, 손실 확률 $1/10$부터 $1/2$, 회복 유무, 지평 5부터 40).
