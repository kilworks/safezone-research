# T-0006

[theory/02-rounding-and-arithmetic.md](../../theory/02-rounding-and-arithmetic.md)에서 발췌했습니다. 전체 맥락, 증명, 테스트는 그곳에 있습니다.

**정리 [T-0006](../theorems/T-0006.md).** 아이템 슬롯 또는 최대 HP +10의 $k$번째 구매($k = 0, 1, \dots$)가 $40 + 10k$ 블러드 토큰이라면, 처음 $n$번의 구매 비용은 $C(n) = 5n^2 + 35n$입니다. 특히 $C(10) = 850$입니다(최대 HP 100에서 200까지). 구매 $k$에서 사는 최대 HP 1포인트의 비용은 $4 + k$ 토큰입니다.

*증명.* $\sum_{k=0}^{n-1}(40 + 10k) = 40n + 10\,n(n-1)/2 = 5n^2 + 35n$. $\square$
*Ingenuity.* Ingenuity는 10% 더 많이 지불하며 올림합니다. 모든 사다리 가격은 10의 배수이므로 $\lceil 11p/10 \rceil = 11p/10$이 정확히 성립하고, 최대 HP 열 번의 구매는 $1.1 \times 850 = 935$ 토큰입니다.
*라벨:* `DERIVED`; 슬롯 사다리와 HP 사다리가 하나의 카운터를 공유하는지는 상인 형식화의 문제입니다. *테스트:* `test_t0006_merchant_ladder`.
