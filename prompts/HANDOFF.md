## Traps already hit

- Bilingual rule: any change to a kb record, `codex/intros.yaml`, `theory/*.md` or `README.md` must update its Korean twin in `ko/` in the same commit. `check_ko.py` fails on a missing field, id or number; `build_codex.py --lang ko` refuses to write with a missing translation. New theorem lines in `ko/theory/` use `**정리 T-xxxx.**`.

- A Python script passed through a Bash heredoc loses its backslashes: write it to the scratchpad with Write, then run it.
- Wayback `id_` captures are stored gzip as downloaded; `tools/page_text.py` decompresses on read so hashes stay those of the bytes downloaded.
- archive.org refuses connections above about 15 requests per minute: `tools/wayback.py` paces at 5 s.
- `np.linalg.inv` saturates near 1e16 on near-singular chains: exact answers need `fractions.Fraction`.
- Subagents lost all work at a session cut because they wrote at the end: they must write file by file, in a disjoint ID range each (M-0100.., M-0200.., ...).
- Even with a quoted heredoc (`<<'EOF'`), Bash ate backslashes in a Python script: `\rfloor` became a carriage return. Always Write the script to the scratchpad. Python `read_text` turns a stray CR into a newline, so repair with `open(..., newline='')`.
