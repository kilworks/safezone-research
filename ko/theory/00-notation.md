# 00. 표기법과 규약

이 파일은 `theory/`의 다른 모든 파일과 Codex에서 쓰이는 기호를 확정합니다.

## 규칙의 출처

모든 규칙은 2026-11-11의 공식 위키 스냅샷(`corpus/manifest.json`)에서 가져왔습니다. `corpus/diffs/`의 이전 캡처는 이벤트의 앞선 판을 설명하는 기록일 뿐이며, 어떤 정리, 모델, 시뮬레이션도 이를 사용하지 않습니다.

## 기호

| 기호 | 의미 | 단위 |
|---|---|---|
| $h$ | 참가자의 현재 HP | HP (정수) |
| $M$ | 참가자의 최대 HP | HP (정수) |
| $d$ | 타격 파이프라인의 한 단계 이전의 정수 피해량 | HP |
| $t$ | 어떤 사건 이후 경과 시간 | 초 (별도 언급이 없으면 정수) |
| $p$ | 상인의 기본 가격 | 블러드 토큰 (정수) |
| $k$ | 같은 업그레이드의 이전 구매 횟수 | 횟수 |
| $n$ | 시도, 구매 또는 참가자의 수 (각 위치에서 명시) | 횟수 |
| $\lfloor x \rfloor$, $\lceil x \rceil$ | 내림과 올림 | |
| $\mathbb{1}[P]$ | $P$가 성립하면 1, 아니면 0 | |
| $a \mid b$ | $a$가 $b$를 나눔 | |
| $\Phi(d, s)$ | 상태 $s$의 방어자가 원래 타격 $d$로 실제로 잃는 HP | HP |

`kb/`의 기록이 달리 증명하지 않는 한, 모든 HP, 피해, 가격, 지속 시간은 정수입니다. 백분율은 정확한 분수로 씁니다. "10% 감소, 내림"은 $\lfloor 9d/10 \rfloor$ 또는 $d - \lfloor d/10 \rfloor$이며, $0.9d$가 아닙니다.

## 신뢰도 라벨

모든 진술에는 라벨이 하나씩 붙습니다. `DOCUMENTED`(위키가 그렇게 말함, 원문 인용), `DERIVED`(문서화된 규칙만으로 도출되며 증명 또는 전수 테스트가 있음), `CONDITIONAL`(문서화된 규칙에 미해결 질문의 명명된 해석 하나를 더하면 도출됨), `CORROBORATED`(독립된 증거가 일치함), `HYPOTHESIS`(그럴듯하지만 증명되지 않았으며, 판정할 테스트가 있음), `CONTRADICTED`(출처가 서로 어긋남), `UNKNOWN`입니다.

## 전수 증명

주장이 유한한 범위의 정수에 관한 것이면, 증명은 모든 값을 확인하는 커밋된 테스트입니다. 범위가 무한하지만 주장이 주기적인 경우(예를 들어 20개 값마다 반복되는 두 내림 식의 차), 증명은 주기를 대수적으로 서술하고 테스트는 한 주기 전체와 여유분을 확인합니다. 테스트는 게임이 아니라 규칙에 대한 우리의 모델을 확인할 뿐입니다. 테스트가 유일한 증거인 곳에서는 본문이 그렇게 밝힙니다.
